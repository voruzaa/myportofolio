## Target Tugas Ini [Anchor](https://pbp.cs.ui.ac.id/assignments/individual/tugas-1.html\#target-tugas-ini)

Lanjutkan halaman “About Me” yang sudah kamu buat di [Tutorial 01](https://pbp.cs.ui.ac.id/tutorial/tutorial-1.html). Tambahkan **satu atau lebih section baru** ke halaman yang sama, dan halaman tersebut masih murni dengan HTML5 dan CSS3. Kamu belum perlu menggunakan database atau menerapkan arsiktektur MVT. Kedua hal tersebut akan dibahas di tutorial selanjutnya.

CatatanTentang Proyek Portofolio

Proyek Individu mata kuliah ini adalah sebuah **website portofolio pribadi**, dikerjakan sendiri. Individual Assignment dirilis tiap minggu mengikuti topik Tutorial minggu itu, dan tiap assignment melanjutkan langsung dari kode yang kamu buat di Tutorial minggu yang sama.

Kamu **bebas memilih** section apa yang mau ditambahkan, selama relevan untuk sebuah portofolio pribadi. Beberapa contoh inspirasi:

- **Skills** \- daftar kemampuan/teknologi yang kamu kuasai.
- **Experience** \- pengalaman organisasi, magang, atau kepanitiaan.
- **Education** \- riwayat pendidikan.
- **Projects** \- proyek-proyek yang pernah kamu kerjakan.

Karena tugas ini sifatnya lebih bebas dibanding Tutorial, kamu dipersilakan membuat tampilan CSS yang lebih kompleks dari contoh di Tutorial 01 - tambahkan animasi, layout grid yang lebih rumit, atau elemen visual lain sesuai kreativitasmu, selama tetap rapi dan responsif.

Tip

Desain visual (warna, font, tata letak, dsb.) di contoh Tutorial 01 hanyalah salah satu referensi. Kamu bebas mengubah desain **seluruh** halaman “About Me”, bukan cuma section barunya, asal tetap murni HTML5 dan CSS3, terstruktur rapi, dan checklist di bawah tetap terpenuhi.

Checklist minimal untuk tugas ini:

- Section “About Me” dari Tutorial 01 sudah terisi dengan data kamu sendiri (nama, NPM, foto, bio - bukan lagi data contoh).
- Minimal membuat satu section baru ke halaman yang sama dengan isi minimal 3 item konten. Misalnya, jika membuat section tentang Skills, maka tuliskan tiga contoh bakat kamu. Atau jika kamu membuat section tentang Projects, maka tuliskan tiga contoh proyek yang pernah kerjakan.
- Section baru tersebut memiliki aturan CSS khusus di `style.css`. Misalnya, menggunakan tata letak/ _layout_ Flexbox/Grid, styling item di dalam section, warna, atau efek _hover_ tersendiri.
- Halaman tetap terlihat rapi di lebar layar desktop maupun mobile.
- Proyek berhasil dijalankan dengan `python manage.py runserver` tanpa error.

## Pertanyaan Reflektif [Anchor](https://pbp.cs.ui.ac.id/assignments/individual/tugas-1.html\#pertanyaan-reflektif)

1. Pada Tutorial dan Tugas 1, Anda diberi kebebasan untuk menentukan tampilan dari website portofolio Anda. Jika iya, bagaimana elemen tersebut membantu Anda dalam membuat _static web_? Jika tidak, mengapa tanpa elemen tersebut sudah memenuhi kebutuhan desain Anda?

## Pengumpulan [Anchor](https://pbp.cs.ui.ac.id/assignments/individual/tugas-1.html\#pengumpulan)

Tugas dikumpulkan lewat slot submisi yang disediakan di SCELE, dalam bentuk **tautan ke commit** (bukan sekadar tautan repositori) di GitHub yang menunjukkan hasil akhir tugas ini, di- _push_ **sebelum tenggat waktu** di bawah. Commit yang di- _push_ setelah tenggat waktu tidak akan diterima. Pastikan repositori GitHub kamu bersifat **publik**, supaya asisten dosen bisa mengaksesnya untuk penilaian.

Format tautan commit yang benar: `https://github.com/<username>/<repository>/commit/<commit-hash>`

Tip

Pastikan _commit_ kamu sudah berhasil di-push ke GitHub. Kamu bisa mengujinya dengan membuka browser di mode Incognito/Private Browsing, lalu coba buka alamat tautan _commit_ yang akan kamu kumpulkan. Jika berhasil dibuka, maka repositori Git kamu di GitHub bisa diakses juga oleh tim pengajar untuk keperluan penilaian.
